| Компонент | Файл | Описание |
|-----------|------|----------|
| Бот | `backend/bot.py` | Основной бот с воронкой, оплатой, выдачей курсов |

## 🚀 Запуск за 5 шагов

### Шаг 1 — Создать бота в Telegram

1. Откройте Telegram → найдите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте имя (например: `Матрицы Судьбы — консультации`) и username (например: `matricy_sudby_bot`)
4. Скопируйте **токен** вида `7123456789:AAHxxxxxxxx`

### Шаг 2 — Узнать свой Telegram ID

1. Напишите боту **@userinfobot** в Telegram
2. Он ответит вашим ID (число, например `987654321`)

### Шаг 3 — Настроить оплату

**Способ А — Kaspi QR (для Казахстана, самый простой):**
1. Откройте приложение `Kaspi.kz`
2. Профиль → Получить деньги → Скопировать ссылку
3. Вставьте в `.env` как `KASPI_QR_LINK=...`

**Способ Б — Telegram Payments (карты Visa/MC):**
1. У @BotFather → `/mybots` → ваш бот → `Payments`
2. Выберите провайдера (PayBox.money работает в Казахстане — сайт: paybox.money)
3. Получите токен и вставьте в `PAYMENT_PROVIDER_TOKEN=`

### Шаг 4 — Создать файл `.env`

```bash
# В папке backend/ создайте файл .env:
BOT_TOKEN=7123456789:AAHxxxxxxxx
ADMIN_TG_ID=987654321
KASPI_QR_LINK=https://kaspi.kz/pay/ВАШ_ЛОГИН
PAYMENT_PROVIDER_TOKEN=      # можно пустым если только Kaspi
```

### Шаг 5 — Установить и запустить

```bash
cd "роза оглы сайт/backend"

# Установить зависимости
pip install -r requirements.txt

# Запустить бота
python bot.py
```

## 📦 Загрузка курсов в бота

После запуска бота напишите ему в Telegram как администратор:

```
/admin
```

Нажмите **"Загрузить файл курса"** → выберите номер курса → отправьте файл PDF/видео или ссылку (Google Drive, Notion и т.д.)

## 🔄 Автоворонка продаж

Бот автоматически отправляет серию сообщений новым пользователям:

| Шаг | Задержка | Содержание |
|-----|---------|------------|
| 0 | Сразу | Приветствие + меню |
| 1 | +1 час | Предложение бесплатной диагностики |
| 2 | +24 часа | Отзывы клиентов |
| 3 | +48 часов | Скидка 10% с промокодом ROZA10 |

Сообщения воронки редактируются в таблице `funnel_messages` базы `bot.db`.

## 🌐 Деплой бота на сервер (чтобы работал 24/7)

### Вариант А — Railway.app (бесплатно, просто)
1. [railway.app](https://railway.app) → New Project → Deploy from GitHub
2. `Add Variable` → добавьте все переменные из .env
3. В `Procfile` (создайте в папке backend):
   ```
   worker: python bot.py
   ```

### Вариант Б — VPS (Timeweb, REG.RU, Beget)
```bash
# На сервере:
git clone https://github.com/ВАШ_РЕПО
cd backend
pip install -r requirements.txt
nohup python bot.py &  # запуск в фоне
```
